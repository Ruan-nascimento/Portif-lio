## 📌 Sobre o projeto

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar minha identidade profissional, meus projetos, minhas habilidades técnicas e minha trajetória como desenvolvedor.

O objetivo do portfólio é funcionar como uma vitrine digital moderna, objetiva e responsiva, reunindo informações sobre mim, minhas formações, experiências, projetos desenvolvidos e formas de contato.

## 🚀 Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias modernas do ecossistema Front-end:

### Front-end

- **Next.js** — framework React para aplicações modernas, performáticas e otimizadas.
- **React** — biblioteca para construção de interfaces.
- **TypeScript** — tipagem estática para maior segurança e organização do código.
- **Tailwind CSS** — estilização rápida, responsiva e baseada em utilitários.
- **CSS Modules / CSS Global** — ajustes visuais e estilizações globais.
- **Framer Motion** — animações fluidas e interativas.
- **GSAP** — animações avançadas para elementos visuais.
- **Three.js** — suporte a recursos visuais 3D, quando necessário.
- **Swiper** — criação de sliders e carrosséis.
- **HeroUI** — componentes visuais modernos.

### Ferramentas de desenvolvimento

- **ESLint** — padronização e análise de código.
- **PostCSS** — processamento de CSS.
- **npm** — gerenciamento de dependências.
- **Git e GitHub** — versionamento e hospedagem do código.
- **Vercel** — deploy da aplicação.
